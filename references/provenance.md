# 来源及版本说明

## 本技能使用的原始文件

- 文内题名：《博士、硕士研究生学位论文写作规范》。封面版本：2018年修订版。
- 原附件文件名：上海理工大学博士、硕士研究生学位论文规范.pdf。13页，569581字节。
- 保存为 [official-writing-standard-2018.pdf](official-writing-standard-2018.pdf)，保持原始字节不变。
- 官方通知：[管理学院关于2026年第二批次研究生学位论文答辩及学位授予相关事项的通知](https://bs.usst.edu.cn/2026/0316/c6097a357405/page.htm)，发布于2026-03-16。
- 官方附件：[硕士答辩相关要求及表格.zip](https://bs.usst.edu.cn/_upload/article/files/eb/9c/cac2d3d24957b6a8c02a92163978/13c982ae-0298-468d-b6a9-7d89c12d8959.zip)。原PDF位于压缩包中的 `硕士答辩相关要求及表格/2.学位论文格式要求/`。
- 来源及附件取得日期：2026-10-26。精确哈希、页数和技能范围记录于 [source.json](source.json)。

附件包以硕士答辩材料命名，但这份PDF自身明确面向博士、硕士研究生，因此可据其博士适用条款构建本技能。该压缩包中的“硕士内封面”并非博士官方模板，本技能不捆绑这些文件。技能中的规则整理和执行建议是整理者的工作成果；原PDF是规范依据。

## 版本和证据强度

1. “2018年修订版”来自文件封面；“2026年通知所附”来自通知。二者不可互换。
2. 一次官网取得记录不能证明未来始终最新。用户要求现行标准或提交资格时，需核验研究生院/学院现行文件及具体适用对象。
3. 文件引用GB/T 7713—1987及GB/T 7714—2015（PDF第3页）。仅据此不能宣称这些国家标准目前仍是最新版本，也不能擅自以新国标替换学校文件已明定的要求。
4. 本技能限定为论文写作与排版规范。原通知中的答辩时间和流程没有转化为永久规则；学术成果认定、查重、AIGC和专业学位特殊要求需分别核验。

## 原文歧义及未覆盖项

| 项目 | 原文情况 | 本技能处理 |
|---|---|---|
| 目录是否收入摘要 | 第6页文字说目录从第一章开始，目录之前内容与目录本身不列入；同页示例却列中文摘要与ABSTRACT | R09默认依文字条款执行；保留冲突。已核验的本届官方模板或院方说明可作为调整依据 |
| 附录公式的连接符 | 第8页正文图表公式按章用点号；第11页附录示例是图A.1、表B.2、式（C-3） | R24把附录公式连字符明确标作沿用示例的工作选择；不声称两种符号已统一 |
| 页码起点与前置页编号 | 第4—5页规定页脚距离、字体、居中和双面复印，未明确前置部分罗马数字或正文页码重置方案 | 使用已确认模板；缺少依据时标待核实，可给明确标注的排版建议 |
| 正文首行缩进及段前后 | 摘要、致谢有明确规定，正文段落通则未单独写出全部参数 | R07区分明定参数和常用实现建议，不把摘要规定自动推广为全文硬性要求 |
| 博士总字数、文献数量等 | 全文无最低总字数或文献数，也无查重/AIGC阈值、发表成果门槛与答辩资格条件 | 不补造数值；按适用学院、培养类型和届次另查 |

## 更新方式

取得新官方文档后保留旧源，记录新文件的发布/修订日期、适用对象及与本规则表的差异。核对受影响的规则、页码、哈希、冲突处理和测试案例后再替换技能依据；仅发现网页日期较新不构成修订证据。
