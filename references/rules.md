# 博士论文规范规则表

依据：[官方原始PDF](official-writing-standard-2018.pdf)，2018年修订版。下文“PDF页”是从封面起计的阅读器页码；PDF第3—13页对应印刷页码1—11。原文“应、须、不得”按要求处理，“一般、建议、可”保持原有强度；“执行建议”是本技能的工作选择。

速查：组成R01；页面R02—R05；封面R06；正文R07；摘要R08；目录R09；标题R10—R12；内容R13；图表公式R14—R19；参考文献R20—R23；附录R24；成果R25；致谢R26；实施换算R27。

## 一、组成与页面

### R01 组成及顺序（PDF第4页，§2.1.1）

原文称“一般包括”，依次为：

1. 封面：外封面、中英文内封面。
2. 学位论文版权使用授权书及声明。
3. 中文摘要及中文关键词。
4. 英文摘要及英文关键词。
5. 目录。
6. 正文。
7. 符号表。
8. 参考文献。
9. 附录（根据论文需要取舍）。
10. 在读期间公开发表的论文和承担科研项目及取得成果一览。
11. 致谢。

外语学院、马克思主义学院有关专业可参照执行。确需注释时，可采用脚注或尾注，按本学科通行范式。原文未为“符号表”另设详细格式或省略条件；无符号表时不要自动判定整篇不合格，注明一般组成要求并核对论文需要及院方口径。

### R02 纸张和边距（PDF第4—5页，§2.1.2）

| 项目 | 要求 |
|---|---|
| 纸张 | A4 |
| 上、下边距 | 3.5 cm、2.5 cm |
| 左、右边距 | 均为3.0 cm |
| 页眉距边界 | 2.0 cm |
| 页脚距边界 | 2.0 cm |

### R03 页眉（PDF第4—5页，§2.1.2）

从摘要到最后，每一页均有页眉；五号宋体，居中，奇偶页不同。

- 奇数页为该部分章标题：摘要、ABSTRACT、目录、各章序号及章标题、参考文献、致谢等。
- 博士论文偶数页为“上海理工大学博士学位论文”。

实现时保留R07的英文、数字字体通则，检查各节实际页眉及奇偶页设置；不要因Word“首页不同”选项意外漏掉章节首页页眉。

### R04 页码（PDF第5页，§2.1.2）

页脚标注页码，五号Times New Roman，居中。原文未明确前置页罗马数字、正文页码重置起点等细节，不把惯常处理说成本PDF明定规则。

### R05 装订（PDF第5页，§2.1.2）

第一章起双面复印，不得有空白页；使用研究生院统一论文封页装订。该句不等于“必须让每章从奇数页开始”。

## 二、封面、正文、摘要及目录

### R06 封面和声明（PDF第5页，§2.2.1—2.2.2）

外封面由学院统一发放，中英文内封面、版权使用授权书及声明可从研究生院网站下载。中英文题目一般不超过30字（词）。本PDF没有博士内封面的具体可编辑模板；正式使用时核验博士模板，缺少信息留待补。不要替作者或导师生成真实签名。

### R07 一般正文（PDF第4页§2.1.2、第7页§2.2.6及示例）

- 中文用宋体，英文和数字用Times New Roman；章标题和各部分专门规定优先。
- 正文示例为小四宋体；一般行距为固定20磅。图表、公式、标题、参考文献及成果一览有各自的例外，不得全篇统一覆盖。
- **执行建议而非本PDF单独明定：**正文段落可采用两端对齐、首行缩进2个汉字符、段前后0磅，供缺少模板时建立工作稿；摘要和致谢的这些参数则有明确条款。

### R08 中英文摘要及关键词（PDF第5—6页，§2.2.3）

摘要概括目的和意义、作者独立研究的主要内容、成果和结论；不少于500字（词）。特殊条件是“留学生如用英文撰写毕业论文”：博士须提供2000字左右中文摘要，不能推广为所有英文博士论文的统一要求。

| 对象 | 字体/字号及对齐 | 行距 | 段前/段后（磅） |
|---|---|---|---|
| 中文标题“摘要” | 黑体小二，居中 | 单倍 | 24 / 18 |
| 中文摘要内容 | 宋体小四，两端对齐，首行缩进2汉字符 | 固定20磅 | 0 / 0 |
| 英文标题“ABSTRACT” | Times New Roman小二，居中 | 单倍 | 24 / 18 |
| 英文摘要内容 | Times New Roman小四，两端对齐，首行缩进2汉字符 | 固定20磅 | 0 / 0 |

关键词3—8个，置于摘要页下方另起一行。中文关键词用宋体四号加粗，词组间空格分隔；英文关键词用Times New Roman四号加粗，词组间英文逗号分隔。原文没有为关键词另定统一的段距。

### R09 目录（PDF第6页，§2.2.4）

- 文字条款：目录一般从第一章引言开始，目录之前内容及目录本身不列入；一般列到三级标题，即二级节标题，如1.1.1。
- 标题“目录”：黑体小二、居中、单倍、段前24磅、段后18磅。
- 内容：宋体小四、固定20磅、段前后0；章节序号、标题和页码相对应。
- 章标题行居左，一级节标题行缩进1汉字符，二级节标题行缩进2汉字符。
- **原文冲突：**同页示例列出“中文摘要”和“ABSTRACT”，与上述文字条款不一致。默认工作稿依文字条款，从第一章开始；说明采用此解释。若已有本届官方模板或学院明确说明，记录依据后调整。目录自身不列入没有对应示例冲突。

## 三、标题和正文内容

### R10 章标题（PDF第7页，§2.2.5）

如“第二章 研究方法”：中文数字章序号，序号与题名间空1汉字符；黑体小二、居中、单倍、段前24磅、段后18磅。与章平级的其他标题同样处理，英文摘要标题按R08专门要求。

### R11 一级节标题（PDF第7页，§2.2.5）

如“2.1 研究设计”：阿拉伯数字、半角点号，编号与题名间空1汉字符；宋体四号加粗、居左、固定20磅、段前24磅、段后6磅。

### R12 二级节标题（PDF第7页，§2.2.5）

如“2.1.1 变量定义”：编号与题名间空1汉字符；宋体小四加粗、居左、固定20磅、段前12磅、段后6磅。无特殊情况不建议使用三级及以上**节**标题。“三级标题”通常指章、一级节、二级节，不要混同“三级节标题”。

### R13 内容要求（PDF第7页，§2.2.6）

- 引言：选题意义、国内外研究现状、拟解决问题、主要理论与方法、基本思路、论文结构。
- 理论：运用前人或本人的理论方法解决未解决的问题，形成新见解或新内容；概念清楚、分析严谨、推导正确。
- 实验、数据处理与分析：原文要求建立比较先进的实验装置、采用新的实验方法并获得实验结果，同时对结果作理论上的阐述、分析和讨论。利用已有数据资料时，原文要求“应用新的理论、新的数据处理方法”进行分析、处理并讨论结果；保留此并列表述，不改写成任选其一。
- 结论：明确、精炼、完整、准确，突出自己的创造性成果或新见解。

这些是内容要求，不限定管理学论文采用物理实验或固定章节数，也不是总字数、发表成果数量或答辩资格标准。

## 四、图表及表达式

### R14 编号（PDF第8页，§2.2.7）

图、表、表达式分别按章编号，以半角点号连接章号和本章顺序号，如图2.1、表3.1、式（1.2）。原文“两位阿拉伯数字”按其章号及顺序号解释，不额外施加“每章最多9项”的限制。

### R15 图和图题（PDF第8页，§2.2.7）

- 图应自明、清晰，坐标比例不过分放大；同一图不同曲线使用不同形状的点标识，术语、符号、单位与正文一致。
- 图题在图下：宋体小四、居中、单倍、段前6磅、段后12磅；图序与名称空1汉字符；图不可跨页。
- 图内标注一般为宋体五号，以可清晰阅读为准。专用名字代号、单位可用外文；坐标轴题名、词组和描述性词语须用中文。
- 多分图使用(a)、(b)、(c)等，并有分图名。需要英文图名时，中英对照，英文另起一行置于中文下方，序号与内容一致。

### R16 表和表题（PDF第8页，§2.2.7）

- 表应直观明了，表中参数应标明量和单位的符号；**建议**三线表，不改写为一律强制。
- 表题在表上：宋体小四、居中、单倍、段前12磅、段后6磅；序号与名称空1汉字符。
- 单元格文字一般宋体五号、单倍、段前后各3磅。
- 大表一页排不下可用续表，每页表序前加“续”，如“续表2.1 名称”，格式同前。不是所有表都禁止跨页。

### R17 表资料来源及双语表名（PDF第8页，§2.2.7）

若在表下方注明资料来源，此部分用宋体小四、单倍、段前6磅、段后12磅；需要续表时，资料来源放在续表之下。本条不能单独推出每张表都必须增设来源行；引用材料的著录义务仍按R20处理。需要英文表名时另起一行放中文下方，英文序号与内容和中文一致，如Table 2.1。

### R18 独立表达式（PDF第9页，§2.2.7）

与正文相同字号，居中；序号用括号，放右边行末，序号与式子间不加连线。单倍行距，段前后各6磅。

### R19 行内表达式（PDF第9页，§2.2.7）

表达式非独立成行时，其所在段落采用单倍行距，段前后各3磅。排版后检查上下标、分式和长公式，不能仅凭样式数值断言显示完整。

## 五、参考文献

### R20 格式和对应关系（PDF第9页，§2.2.8）

参考文献为必要组成部分。引用权威和最新文献并实事求是；已引用文献必须著录，未引用文献不得列入。

- 标题与章标题相同：黑体小二、居中、单倍、段前24、段后18磅。
- 条目中文宋体小四，英文Times New Roman小四；固定16磅，段前3、段后0磅，标点半角。
- 顺序编码制与著者—出版年制任选其一，全文一致，正文引文和列表一一对应。
- 原文示例按文献类型分类只是为说明格式，实际列表不按期刊、专著等分组。

### R21 顺序编码制（PDF第9页，§2.2.8）

按正文（包括图、表及说明）引用先后顺序编号，序号放方括号内，在引文后以上标形式标注。PDF给出多篇、连续范围示例；不把示例中的具体编号或文献当作用户已引用文献。

### R22 著者—出版年制（PDF第9页，§2.2.8）

原文称按引用文献著者和出版年度顺序编号。姓名（或姓）和年份通常放括号内，置于引用句末。正文已提姓名时，后续括号只写年份。多著者：欧美著者用第一著者姓后附et al；中国著者用第一著者姓名后空1格加“等”。原文示例：张三（2016）、（张三 等, 2016）。本PDF未给出多语种排序、同作者同年字母后缀等详细实现规则，需要时另查适用模板或标准。

### R23 文献类型和网络来源（PDF第10—11页，§2.2.8示例）

按实际文献类型著录，缺失信息需查证；下列是字段模式，非可直接用于论文的真实条目。

| 类型 | 原文示例对应的主要字段 |
|---|---|
| 期刊[J] | 作者、文章标题、刊名、出版年、卷（期）、页码；无卷期刊可不写卷 |
| 专利[P] | 申请者、题名、国别、专利号、公告或公开日期 |
| 图书[M] | 作者、书名、译者等（无则省略）、版次（初版不注）、出版地、出版者、出版年、页码 |
| 论文集析出文献[C] | 作者、篇名、译者等（无则省略）、//文集编者、文集名、版次、出版地、出版者、出版年、页码 |
| 电子文献[类型/载体] | 作者、题名、出版地/出版者/出版年（通常没有时可不著录）、引用日期、获取和访问路径 |
| 标准[S] | 标准编号、标准名称；责任者、出版地、出版者、出版年按原文示例为任选 |
| 学位论文[D]、科技报告[R] | 作者、名称、存放地、存放者、完成时间 |

网络版期刊、图书、论文集补充引用日期及获取/访问路径；纸质版本不需这些网络字段。电子图书、电子期刊仍按图书/期刊类别，不因在线获取全部改成EB/OL。PDF第11页夹带的“和上面说明的字体不一样”是源文编辑性批注，不是论文必须出现的文字。

## 六、附录、成果与致谢

### R24 附录（PDF第11页，§2.2.9）

按需要设置，可放过长推导、辅助工具和表格、重复数据、必要程序、关键问卷或方案。格式同正文，用A、B、C等编号；只有一个仍叫“附录A”。每个附录有标题，序号与标题空1汉字符。

附录内图、表、表达式、参考文献等与正文另编序号，数字前冠附录字母。原例为“图A.1”“表B.2”“式（C-3）”。

**连接符待核实：**正文公式示例为点号，附录公式示例为连字符。工作稿默认沿用附录公式示例，写（A-1）、（A-2）等，明确这是示例支持的执行选择；不能声称原文明定附录公式一律用点号。已有经核实的博士模板或学院说明时从其规定并记录依据。

### R25 在读期间成果（PDF第12页，§2.2.10）

按一定顺序列本人攻读学位期间已发表或已录用论文、专利和主持/参与项目等。组成清单称“在读期间公开发表的论文和承担科研项目及取得成果一览”；正文标题说明省略“一览”，采用模板时保留其题名，不把题名细微差异当成学术不合格。

- 大标题与章标题相同。
- 论文、专利、科研项目小标题：宋体四号加粗、居左、固定20磅，段前24、段后6磅。
- 内容格式同参考文献：中文宋体小四、英文Times New Roman小四，固定16磅，段前3、段后0磅。
- 专利列级别、名称、授权号或申请号、发明人排序；项目列来源、名称和编号、起止时间、参与级别等。按真实状态区分录用/发表、申请/授权、负责人/参与人；无依据不补造。

### R26 致谢（PDF第13页，§2.2.11）

感谢对论文工作有直接贡献和帮助的导师、人士和单位，谦虚诚恳、实事求是；篇幅一般不超过1页。标题同章标题；内容宋体小四、两端对齐、首行缩进2汉字符、固定20磅、段前后0。

## 七、实施换算与审查范围

### R27 字号与布局换算（软件实现说明，非学校新增规则）

上述字号的常用点数映射：小二18 pt、四号14 pt、小四12 pt、五号10.5 pt。Word的“固定值20磅”须区别于“1.5倍行距”；字号数值也不是行距。A4尺寸为210×297 mm；软件中可直接用厘米/毫米单位。替代字体、缺字、公式裁切与分页应通过渲染确认，不能仅凭点数一致宣称排版一致。

仅凭文本抽取不能确认字号、分节、奇偶页、图题位置和打印空白页。整篇检查、抽查若干页、检查单个条目是不同的完成范围，应按实际结果报告。
